EventPilot - חלק ב' (צד לקוח)

הפעלה:
1. לפתוח את התיקייה ב-VS Code ולהפעיל את index.html עם Live Server
   או להריץ בתיקייה:  python -m http.server   ולגלוש אל http://localhost:8000
2. משתמש הדגמה:  demo@eventpilot.com   סיסמה:  Demo1234

מבנה:
index.html    כניסה והרשמה
events.html   האירועים שלי
event.html    האירוע שלי (תמונת מצב ומשימות)
guests.html   מוזמנים
vendors.html  ספקים ותקציב
seating.html  סידורי ישיבה
rsvp.html     אישור הגעה לאורח (נפתח מקישור אישי, בלי התחברות)

css/style.css      כל העיצוב
js/storage.js      שכבת הנתונים (מדמה שרת ובסיס נתונים בעזרת localStorage)
js/validation.js   בדיקות קלט משותפות
js/common.js       ניווט, הודעות ופונקציות עזר
js/<page>.js       הקוד של כל עמוד

איפוס נתונים: כלי המפתחים בדפדפן > Application > Local Storage > מחיקה.
