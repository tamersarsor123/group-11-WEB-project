# EventPilot – קבוצה 11

אפליקציית Web לניהול אירועים: מוזמנים ואישורי הגעה בקישור אישי, ספקים ותקציב, וסידורי ישיבה.

## הפעלה

1. פותחים את `index.html` בדפדפן (לחיצה כפולה), או מפעילים אותו עם Live Server ב-VS Code.
2. נכנסים עם משתמש ההדגמה: `demo@eventpilot.com` / `Demo1234`.
3. איפוס לנתוני ההדגמה: F12 > Application > Local Storage > מחיקה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כניסה והרשמה |
| `events.html` | האירועים שלי |
| `event.html` | האירוע שלי: פרטים, סיכום ומשימות |
| `guests.html` | מוזמנים |
| `vendors.html` | ספקים ותקציב |
| `seating.html` | סידורי ישיבה ומפת שולחנות |
| `rsvp.html` | אישור הגעה לאורח (נפתח מהקישור האישי) |
| `css/style.css` | כל העיצוב |
| `js/storage.js` | שכבת הנתונים (מדמה שרת בעזרת localStorage) |
| `js/validation.js` | בדיקות קלט משותפות |
| `js/common.js` | ניווט, אייקונים והודעות |
| `js/<עמוד>.js` | הקוד של כל עמוד |
